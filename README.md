# OIBSIP Web Development Internship Projects

This repository contains the web development projects I completed during my **Oasis Infobyte Web Development Internship (OIBSIP)**. The projects demonstrate my practical experience with **HTML, CSS, and JavaScript**, with an emphasis on creating responsive, user-friendly, and visually appealing web interfaces.

## 📂 Projects Included

The repository includes the following projects:

* **Landing Page** – A responsive landing page designed to demonstrate webpage structure, navigation, layout, and modern styling.
* **Portfolio / Profile Website** – A personal portfolio website showcasing skills, projects, and web development experience.
* **Temperature Converter** – A simple web application that allows users to convert temperatures between different units.

## 🚀 Features

* Clean and well-structured code
* Responsive layouts for different screen sizes
* User-friendly and visually appealing interfaces
* Organized project folders for easier navigation
* Separate HTML, CSS, and JavaScript files where required
* Practical implementation of front-end web development concepts

## 🛠️ Technologies Used

* **HTML5** – For creating the structure and content of the webpages
* **CSS3** – For styling, layouts, animations, and responsive design
* **JavaScript** – For interactive functionality and dynamic features

## 📖 How to Use

1. Clone or download this repository from GitHub.
2. Open the repository folder on your computer.
3. Open the main `index.html` file in a web browser.
4. Use the navigation links on the main page to access the different projects:

   * **Landing Page** 🌐
   * **Portfolio / Profile** 💼
   * **Temperature Converter** 🌡️
5. Each project is organized within its respective folder.
6. Open the relevant `index.html` file to run a project locally.
7. The projects can be viewed directly in a modern web browser without requiring additional software or a server.
8. The responsive designs allow the projects to be accessed on both **desktop and mobile devices**. 📱

## ✨ Internship Context

These projects were developed as part of my **Oasis Infobyte Web Development Internship (OIBSIP)**. The internship provided an opportunity to apply web development concepts in practical projects while improving my skills in **front-end development, responsive design, problem-solving, and user interface development**.

Through these tasks, I gained valuable hands-on experience in building functional and visually appealing websites using modern web technologies.
