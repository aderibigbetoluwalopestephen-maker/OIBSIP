# OIBSIP WebDev L1 Task 3 — Temperature Converter

A responsive temperature conversion website built with **HTML5, CSS3 and Vanilla JavaScript** for the Oasis Infobyte Web Development & Designing internship.

## Features
- Numeric input validation
- Celsius, Fahrenheit and Kelvin units
- Convert button and result area
- Celsius/Fahrenheit/Kelvin conversion formulas
- Absolute-zero validation
- Responsive, centered interface
- Purple visual identity

## Technologies
HTML5, CSS3, Vanilla JavaScript

## Run
Open `index.html` in a modern browser.
